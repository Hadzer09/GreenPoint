# 🌿 GreenPoint - Sustainable Life Ecosystem

**GreenPoint** adalah platform digital inovatif yang menjembatani masyarakat dengan pengelolaan sampah berkelanjutan. Melalui aplikasi ini, nasabah dapat menyetorkan sampah rumah tangga, memantau dampak lingkungan mereka, dan menukarkan hasil setoran menjadi saldo uang digital atau poin reward.

### 🚀 Fitur Utama:
- **Real-time Dashboard:** Pantau total berat sampah, pendapatan, saldo, dan Eco Poin secara instan.
- **Setoran Sampah:** Sistem pencatatan setoran yang terintegrasi dengan kategori sampah (Logam, Kertas, Plastik).
- **Laporan Saya:** Riwayat transaksi lengkap untuk transparansi data nasabah.
- **Redeem System (Ongoing):** Penukaran saldo ke E-Wallet (DANA/OVO) dan merchandise menarik.

### 🛠️ Tech Stack:
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS.
- **Backend:** Laravel (RESTful API), MySQL.
- **State Management:** React Hooks (useEffect, useState).
- **Authentication:** Laravel Sanctum (Bearer Token).
