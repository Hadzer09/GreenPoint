# 🌿 GreenPoint - Sustainable Life Ecosystem

**GreenPoint** is an innovative digital platform that bridges the gap between the community and sustainable waste management. Through this application, users can deposit household waste, track their environmental impact, and convert their contributions into digital balance or reward points.

### 🚀 Key Features:
- **Real-time Dashboard:** Instantly monitor total waste weight, earnings, balance, and Eco Points.
- **Waste Deposits:** Integrated recording system categorized by waste types (Metal, Paper, Plastic).
- **My Reports:** Complete transaction history for user data transparency.
- **Redeem System (Ongoing):** Convert balance to E-Wallets (DANA/OVO) and claim exciting merchandise.

### 🛠️ Tech Stack:
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS.
- **Backend:** Laravel (RESTful API), MySQL.
- **State Management:** React Hooks (useEffect, useState).
- **Authentication:** Laravel Sanctum (Bearer Token).
